# TomatKu

Aplikasi web untuk mendeteksi kondisi daun tomat.

## Fitur

- Edukasi kondisi daun tomat
- Deteksi daun melalui kamera atau foto
- Statistik hasil deteksi
- Riwayat pemindaian
